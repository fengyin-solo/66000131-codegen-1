# 生成艺术 SVG 海报设计器

参数化生成艺术工具，支持螺旋、分形树、波浪、圆环、噪声场五种图案，8 种颜色主题，SVG/PNG 导出。

## 功能

- 5 种图案类型：螺旋、分形树、波浪、圆环、噪声场
- 8 种预设颜色主题（日落、海洋、霓虹、森林、单色、糖果、火焰、极光）
- 种子随机数生成器（确定性重现）
- 参数实时预览：迭代数、缩放、旋转、描边、透明度
- 方案收纳：一键保存当前参数，卡片式管理（小预览 / 改名 / 移除 / 点击整组套用）
  - 套用后滑杆、图案按钮、主题高亮与画面同步；手动改动任意一项后卡片标记为「已调整」
  - 空名/重名给出可读提醒并保留输入；方案经 localStorage 本地持久化，重开页面仍在
- SVG 矢量导出 & PNG 高清导出

## 技术栈

- React + TypeScript + Vite
- D3.js（数据处理）
- Zustand（状态管理）
- Tailwind CSS

## 运行

```bash
cd frontend && npm install && npm run dev
```
